= Using the Bastion Terminal

The *Bastion Terminal* tab opens a shell on the bastion host as the `{user}`
user. The bastion already has the OpenShift CLI (`oc`) and the cluster
kubeconfig configured.

== Confirm access

[source,sh,role=execute]
----
oc whoami
----

== See the cluster nodes

[source,sh,role=execute]
----
oc get nodes
----

A single-node cluster shows one node carrying both the `control-plane` and
`worker` roles; compact and standard clusters show three or more nodes. List
the roles for every node:

[source,sh,role=execute]
----
oc get nodes -o custom-columns=NAME:.metadata.name,ROLES:.metadata.labels
----
