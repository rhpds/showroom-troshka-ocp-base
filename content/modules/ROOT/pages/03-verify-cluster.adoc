= Verify the Cluster

Run these checks from the *Bastion Terminal*.

== Node status

[source,sh,role=execute]
----
oc get nodes -o wide
----

Every node should report `Ready`.

== Cluster operators

[source,sh,role=execute]
----
oc get clusteroperators
----

Every operator should show `AVAILABLE=True`, `PROGRESSING=False`, and
`DEGRADED=False`. On a freshly booted cluster it can take a few minutes for all
operators to settle.

== Cluster version

[source,sh,role=execute]
----
oc get clusterversion
----

A healthy cluster reports `Available=True` with the expected version.
