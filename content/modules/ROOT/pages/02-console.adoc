= Accessing the OpenShift Console

The *OpenShift Console* tab proxies the OpenShift web console through the
showroom.

== Get the kubeadmin password

This environment is bastionless, so there is no `~/auth` directory to read. The
generated `kubeadmin` password is harvested at install time and shown in the
Troshka UI: open your cluster's install log / *Access* panel in the Troshka
project — the `kubeadmin` password is listed there (click to reveal and copy).

== Log in

Open the *OpenShift Console* tab and log in as `kubeadmin` using that password.

[TIP]
====
The console is served by the cluster ingress router, which routes by hostname.
Troshka's showroom proxies it by name (the `Host` header and TLS SNI are set to
the console's route hostname) so the console's redirects and asset URLs resolve
correctly through the proxy.
====
