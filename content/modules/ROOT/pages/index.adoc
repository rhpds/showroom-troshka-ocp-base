= OpenShift — Base Lab

Welcome to the base OpenShift lab environment, provisioned by Troshka.

Depending on which OCP example you deployed, the cluster is one of:

* *Single Node OpenShift (SNO)* — one node that is both control plane and worker.
* *Compact* — three combined control-plane + worker nodes.
* *Standard* — three control-plane nodes plus one or more workers.

Either way, the environment contains:

* A *Cluster Terminal* — a shell inside the showroom with the OpenShift CLI
  (`oc`) and the kubeconfig for every deployed cluster already in place. There
  is *no bastion host*: the cluster is installed bastionless, from a
  short-lived ops pod, using the Agent-based Installer.
* The *OpenShift cluster* itself.
* A *BMC network* used to provision the nodes via Redfish virtual media.

Work through the lab using the tabs on the right:

* *Cluster Terminal* — a shell with `oc` pre-configured.
* *OpenShift Console* — the OpenShift web console.
