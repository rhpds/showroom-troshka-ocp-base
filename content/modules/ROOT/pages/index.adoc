= Single Node OpenShift — Base Lab

Welcome to the Single Node OpenShift (SNO) base lab environment, provisioned by
Troshka.

This environment contains:

* A *bastion* host (RHEL) with the OpenShift CLI (`oc`) and the cluster
  kubeconfig already in place — use it to drive the lab.
* A *single-node OpenShift cluster* (`cp-0`) — one node that is both the control
  plane and the worker.
* A *BMC network* used to provision the node via Redfish virtual media.

Work through the lab using the tabs on the right:

* *Bastion Terminal* — a shell on the bastion host.
* *OCP Console* — the OpenShift web console.
